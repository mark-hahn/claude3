The text of the middle-click and ? popups (src/keyHelp.ts). A line starting with @ names an item;
the lines after it, up to the next @ line, are its popup text, blank lines included. The name is the
element's data-help (middle-click) or data-mode (the ? button's focused part) in the source.
"global keys" is the ? button's own. npm test fails when a name here is in no source file, or a name
in the source has no block here. Lines before the first @ line, like these, are ignored.

@global keys
Middle-click: on any item, how it is used. Nothing on items that only show something. A link keeps its own middle-click (a new background tab).
Ctrl-B: hide or show the sidebar.
Ctrl-S: a new session, as +. On an empty new session with nothing typed, back to the session before it.
Ctrl-G: open or close the Git popup.
Ctrl-Alt-Z: the big prompt editor on or off (the prompt box full height left of the history).
Ctrl-Alt-X: in the big prompt editor, the prompt shown as markdown, and back.
Enter: anywhere outside a text box or the footer, selects and opens the last block; again, opens or closes its box.
Ctrl-wheel: text size of the history, Files tree and editor, Log, Snips and terminal, each remembered.
Alt-click: copies a bar's prompt, a box's text, a code block, a card's name, a Files row's path, a Log row's message.
In a dialog: Enter presses its default button, Esc or a click on the gray outside closes it.
Ctrl-R: reload the page (also in the terminal).

@keys button
Click: this list: the global keys, and the keys of the part that has the focus (named on its first line).

@sidebar button
Click: hide or show this tab's sidebar (the session list). Same as Ctrl-B. Not on the trash list.

@new session button

The label counts the changed files; highlighted when there are any. Off when the folder is in no git repo.

Highlighted when files changed since the last deploy.
